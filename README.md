## What I did
- Imported and cleaned four related sources: handled missing values, duplicates, formatting and inconsistencies
- Built a data model with relationships between the tables
- Created 5 calculated columns and 4 DAX measures
- Designed an interactive dashboard with KPI cards, maps and slicers
- Published the report to Power BI Service

## Tools
Power BI, DAX, Data Modeling

## Files
- `Sales.pbix`: the Power BI report
